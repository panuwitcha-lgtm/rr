# Health Chair ตัวจำลองใน Wokwi

จำลองเก้าอี้ (ESP32-S3 + FSR 6 ตัว + MPU6050) แล้วส่งข้อมูลขึ้น **ThingsBoard Cloud** จริง ให้ไปขึ้นที่**หน้าเว็บ Health Chair**
ไม่ต้องมีบอร์ดหรือแบต ใช้ได้ทั้ง **VS Code (Wokwi for VS Code + PlatformIO)** และเว็บ **wokwi.com**

```
Wokwi (เก้าอี้จำลอง)  --MQTT-->  ThingsBoard Cloud  --REST/WebSocket-->  หน้าเว็บ Health Chair
      TB_TOKEN ของ device X            device X                 ล็อกอินบัญชีที่เห็น device X
```

**ต้องตรงกัน 2 อย่าง ข้อมูลถึงจะขึ้นเว็บ**
1. `TB_TOKEN` ใน `src/config.h` = access token ของ device ใน ThingsBoard
2. บัญชีที่ใช้ล็อกอินหน้าเว็บ ต้อง**มองเห็น device นั้น** (เป็นเจ้าของบัญชี ThingsBoard หรือได้รับสิทธิ์อ่านอุปกรณ์)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `src/sketch.ino` | โค้ดหลัก (v1.5.0-wokwi) Terminal บอกท่านั่งเป็นภาษาไทยอ่านง่าย |
| `src/config.h` | ค่าตั้ง **แก้แค่ `TB_TOKEN`** (ตั้ง `LOG_THAI 0` ถ้าอยากได้ภาษาอังกฤษ) |
| `diagram.json` | วงจร: ESP32-S3 + MPU6050 + slide 7 ตัว + buzzer + LED 2 ดวง (เปิดมาจะตั้งท่า "นั่งตรง" ไว้ให้แล้ว) |
| `platformio.ini`, `wokwi.toml` | สำหรับ VS Code |
| `libraries.txt` | สำหรับ wokwi.com |

## วิธีรันใน VS Code (แบบที่ใช้อยู่)

ต้องมี extension **PlatformIO IDE** และ **Wokwi Simulator** (ต้อง activate license ฟรีของ Wokwi ครั้งแรก)

1. VS Code → **File → Open Folder...** → เลือกโฟลเดอร์ `wokwi` นี้ (โฟลเดอร์ที่มี `platformio.ini`)
2. เปิด `src/config.h` ใส่ `TB_TOKEN` (ถ้าเคยใส่ไว้ในโปรเจกต์เก่า ก็อปบรรทัดนั้นมาวางได้เลย) แล้วเซฟ
3. กด **PlatformIO: Build** (ไอคอน ✓ ด้านล่าง) ครั้งแรกจะโหลด library นานหน่อย
4. กด **F1** → พิมพ์ `Wokwi: Start Simulator`
5. ดูที่แท็บ **Terminal** ด้านล่าง (Wokwi Terminal)

> แก้โค้ดหรือ `config.h` แล้วต้องกด **Build ใหม่ทุกครั้ง** ก่อน Start Simulator ไม่งั้น Wokwi จะรันไฟล์เก่า

## วิธีรันบน wokwi.com

1. เปิด https://wokwi.com/projects/new/esp32-s3
2. แท็บ `sketch.ino`: ลบของเดิม วางเนื้อหา `src/sketch.ino`
3. แท็บ `diagram.json`: ลบของเดิม วางเนื้อหา `diagram.json`
4. ลูกศร ▾ ข้างแท็บ → **New file...** → `config.h` → วางเนื้อหา `src/config.h` แล้วใส่ `TB_TOKEN`
5. **New file...** อีกครั้ง → `libraries.txt` → วางเนื้อหา `libraries.txt`
6. กด ▶ สีเขียว

## Terminal บอกอะไรบ้าง

ตอนเปิดเครื่อง:
```
==============================================
 Health Chair 1.5.0-wokwi (Wokwi)
 จำแนกท่า : เกณฑ์ค่า FSR
 MPU6050  : เจอ
 ThingsBoard: thingsboard.cloud | token: ใส่แล้ว
 วิธีเล่น: เลื่อน slide FSR1-4 = เบาะ, FSR5-6 = พนักพิง (ขวา = กดแรง)
==============================================
 แบตเตอรี่ 3.96 V (73%)
>> เชื่อม ThingsBoard สำเร็จ (thingsboard.cloud) ข้อมูลจะขึ้นหน้าเว็บ Health Chair แล้ว
```

ตอนมีคนนั่ง (ทุก 1 วินาที และทันทีที่ท่าเปลี่ยน):
```
---- นั่งมาแล้ว 00:42 | ท่า: เอียงซ้าย  [ผิดท่า 4/10 วินาที] | ThingsBoard เชื่อมแล้ว ส่งไป 12 ข้อความ
     ซ้าย-ขวา : ซ้าย 88% | ขวา 12%  -> ซ้ายหนักกว่าขวา 75% (เกิน 35% = เอียงซ้าย ผิดท่า)
     หน้า-หลัง: หน้า 50% | หลัง 50% | พนักพิง เอว 40% บน 40% | พนักพิงเอน 0.0 องศา
```

| ส่วน | ความหมาย |
|---|---|
| `ซ้าย 88% \| ขวา 12%` | น้ำหนักบนเบาะฝั่งซ้าย (FSR1+FSR3) กับฝั่งขวา (FSR2+FSR4) รวมกันได้ 100% |
| `ซ้ายหนักกว่าขวา 75%` | ส่วนต่างซ้าย-ขวา **เกิน 35% = เอียง** (ไม่เกินยังนับว่านั่งตรง) |
| `หน้า 89% \| หลัง 11%` | น้ำหนักเบาะหน้า (FSR1+FSR2) กับเบาะหลัง (FSR3+FSR4) หน้ามากกว่าหลัง 2 เท่าและไม่พิงพนัก = นั่งขอบเก้าอี้ |
| `พนักพิง เอว 40% บน 40%` | แรงกด FSR5 / FSR6 ถ้ารวมกันต่ำกว่า 5% จะขึ้น `(ไม่พิงพนัก)` = โน้มตัวไปหน้า |
| `พนักพิงเอน 0.0 องศา` | จาก MPU6050 เกิน 12 องศา = เอนหลังมากไป |
| `[ผิดท่า 4/10 วินาที]` | นั่งผิดท่ามากี่วินาทีแล้ว ครบ 10 วินาทีจะเตือน (LED แดง + buzzer) และขึ้น `[!! เตือนนั่งผิดท่า]` |
| `ThingsBoard เชื่อมแล้ว ส่งไป N ข้อความ` | N เพิ่มขึ้นเรื่อย ๆ = ข้อมูลขึ้น ThingsBoard แล้ว |

ตอนเก้าอี้ว่าง (ทุก 5 วินาที):
```
[ว่าง] ไม่มีคนนั่ง | แรงกดบนเบาะ 0% (ต้องเกิน 4% ถึงนับว่านั่ง) | แบต 3.96 V | ThingsBoard เชื่อมแล้ว ส่งไป 3 ข้อความ
```

## ลองท่านั่งต่าง ๆ

เลื่อน slide ไปทางขวา = กดแรงขึ้น (0-100)

| อยากได้ท่า | fsr1, fsr2, fsr3, fsr4 (เบาะ) | fsr5, fsr6 (พนักพิง) |
|---|---|---|
| ไม่มีคนนั่ง | 0, 0, 0, 0 | ค้าง 60 วินาทีจะขึ้น "ลุกจากเก้าอี้แล้ว" |
| นั่งตัวตรง (ค่าเริ่มต้น) | 50, 50, 50, 50 | 40, 40 |
| เอียงซ้าย | 70, 10, 70, 10 | 40, 40 |
| เอียงขวา | 10, 70, 10, 70 | 40, 40 |
| โน้มตัวไปหน้า | 50, 50, 50, 50 | 0, 0 |
| นั่งขอบเก้าอี้ | 80, 80, 10, 10 | 0, 0 |
| เอนหลังมากไป | 50, 50, 50, 50 | 0, 40 (เอวไม่แตะ) หรือคลิก MPU6050 แล้วเลื่อน accelY ~0.3 g |

- เตือนนั่งนาน: แก้ `SIT_LIMIT_MIN` ใน `config.h` เป็น `1` จะได้ไม่ต้องรอ 45 นาที
- แบต: เลื่อน slide `vbat` (64 ≈ 4.2 V = 100%, 50 ≈ 3.3 V = 0%)

## ถ้ามีปัญหา

| Terminal ขึ้นว่า | แก้ |
|---|---|
| `ยังไม่ได้ใส่ TB_TOKEN` | ThingsBoard → Devices → เลือกเครื่อง → **Copy access token** → วางใน `src/config.h` → Build ใหม่ |
| `ต่อ ThingsBoard ไม่ได้ rc=5` | token ผิด หรือ device ถูกลบ ก็อป token ใหม่ |
| `ต่อ ThingsBoard ไม่ได้ rc=-2` | เน็ตของ Wokwi ช้า/หลุด รอสักครู่ โค้ดลองใหม่เอง หรือหยุดแล้วเริ่มจำลองใหม่ |
| `Wi-Fi ต่อไม่ได้` | `WIFI_SSID` ต้องเป็น `Wokwi-GUEST` |
| `MPU6050 : ไม่เจอ` | `diagram.json` ไม่ครบ ก็อปใหม่ทั้งไฟล์ |
| ภาษาไทยเป็นตัวอ่านไม่ออก | ตั้ง `LOG_THAI 0` ใน `config.h` |
| Terminal ส่งได้ (N เพิ่ม) แต่เว็บว่าง | บัญชีที่ล็อกอินเว็บมองไม่เห็น device นี้ ดู README หน้าแรก หัวข้อ "เว็บไม่ขึ้นข้อมูล" |

> ข้อมูลจาก Wokwi แบบฟรีวิ่งผ่านเครื่องกลางของ Wokwi ควรสร้าง device แยกไว้ทดสอบ (เช่น `Health Chair Sim`) ใช้ token ของ device ทดสอบ และอย่ากด Share โปรเจกต์ที่มี token อยู่
